How this works

Your program runs on CPython compiled to WebAssembly, in a background worker, so a program that never stops cannot freeze the page. A tracer watches it line by line and writes down only what it observes. Conditions are recorded as they are computed, so the values shown are the values the program used — nothing is run a second time to display it.

Long programs are stopped at 50,000 steps or 5 seconds, and the trace says it is incomplete rather than pretending otherwise. Explanations from a language model will sit alongside the trace; they will never replace it.
